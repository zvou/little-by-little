# Little by Little: playable demo

A cosy pixel-art planner game: quests water your garden and earn XP and coins for your homestead.
Built with React, TypeScript, Vite and Phaser, with IndexedDB storage and an installable PWA.

**Play it:** https://zvou.github.io/little-by-little/

This repository only holds the built demo. It starts with sample data, and anything you change stays in your own browser.
The source code is private.
